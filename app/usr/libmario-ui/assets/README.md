# `libmario-ui` Assets

These source assets are copied into the GUI ramdisk only when `GUI=true`.

- `fonts/`: bundled DejaVu fonts for desktop and terminal rendering.
- The GUI build copies the TTF files to `rd/usr/share/fonts/`.

The version, source archive, license, and SHA-256 checksums are recorded in
`fonts/FONT-VERSION.txt`.
