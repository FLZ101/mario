# Desktop Assets

`cursor-arrow-16.rgba` is a 16 by 16 raw `RGBA8888` cursor image. Its hot spot
is pixel `(0, 0)`. The build converts the source pixels to Mario's internal
premultiplied ARGB representation; the desktop does not require a runtime PNG
decoder to display it.
