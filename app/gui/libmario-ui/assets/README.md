# `libmario-ui` Assets

These source assets are copied into the shared ramdisk image.

- `fonts/`: bundled DejaVu fonts for the desktop and DejaVu Sans Mono Nerd Font
  for the terminal, including the Braille glyphs used by `btop` graphs.
- The ramdisk build copies the fonts and Nerd Font notices to `/usr/share/fonts/`.

The version, source archive, license, and SHA-256 checksums are recorded in
`fonts/FONT-VERSION.txt`.
